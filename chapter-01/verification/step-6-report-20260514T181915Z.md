## 8. Surprises and notes

### 8.1 Heavier structure → tighter prompt required

War Table has 50 % more structural surface than Visual DNA (6 prose sections + 3 data blocks vs 5 + 2). The model's natural verbosity scales with structural complexity. The lesson: every additional `data_block` requires proportional prompt compression elsewhere. For Chapter 2's agent framework refactor, this argues for a per-section length budget that scales with total structure.

### 8.2 Honest competitor placement

The model used `Harley-Davidson` and `Patagonia` from `archetypeMarketLandscape.occupiers` verbatim, exactly as the prompt instructed. It then added `Hero Archetype` as a fourth placement to anchor the "drift risk" axis. This is the right behavior — the prompt does not require placements to be real companies; it says "competitors or category archetypes", and the Hero placement here functions as the named anti-pattern from the QBP itself.

### 8.3 Bottleneck identified

After three iterations across steps 4–6, the slowest-agent-in-parallel-dispatch is now consistently **Visual DNA**. War Table at 18.9 s is faster than Visual DNA at 20.5 s for the same user. This is because Visual DNA must produce four hex codes with rationales plus a type pairing block plus the prose, while War Table's 3 priorities + 3 placements + 3+3 always/never produce less variable text. Step 18 (full free-tier journey) should target Visual DNA latency first if any agent needs further tuning.

### 8.4 Anthropic key safety

Production env was pulled to `/tmp/qb-prod.env` for the live test and deleted at script exit. Same approach as steps 3, 4, 5.
