### 6.3 Edge runtime portability

The validator has no DOM, no Buffer, no `require()` and no top-level await. It uses only ES2020 primitives. Confirmed to load identically under Node 25 ESM and a browser ES module loader.

### 6.4 Validator strictness

The validator collects all errors (not first-only) and rejects unknown keys at every level the spec defines: top-level, `header`, `body_sections[*]`, `data_blocks[*]`, `data_blocks[*].content` (per type), `footer`, and `footer.related_artifacts[*]`. This catches drift early: a synthesizer that adds a field on its own is rejected at write time, not silently rendered.
