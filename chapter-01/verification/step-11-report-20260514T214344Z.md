## 3. Filter logic summary

State is a 4-tuple held in the URL hash:

```
#phase=01&agent=soul_map_synthesizer&status=delivered&versions=all
```

| Key | Values | Default |
| --- | --- | --- |
| `phase` | `all` / `00` / `01` / `02` / `03` / `04` / `05` | `all` |
| `agent` | `all` / any agent slug present in the user's list | `all` |
| `status` | `all` / `delivered` / `generating` / `failed` / `locked` | `all` |
| `versions` | `latest` / `all` | `latest` |

Default values are omitted from the hash. `#` reduces to empty when no filters active. Filters combine with AND.

**Phase filter:** Phases 02–05 are rendered as `is-disabled` pills (visible but non-interactive) so the structure of the system is legible from Chapter 1 onward. Only Phase 01 is selectable.

**Agent filter:** Only agents that have produced at least one artifact for this user appear as selectable pills. If a user has no Sensescape artifacts, that pill is hidden — no empty filter options.

**Status filter:** Includes a synthetic `locked` value which is computed client-side from each row's `locked` flag (rather than `row.status`).

**Version toggle:** `latest` (default) groups rows by `agent_slug` and keeps the highest `version` per group. `all` shows every row. Counter in the toolbar reads "N of M artifacts" reflecting filtered vs total.

**Reset button:** Visible only when any of `phase` / `agent` / `status` is non-default. Clears those three; preserves `versions`.

**Hashchange listener:** Re-renders when the hash changes outside the in-component update path (e.g. browser back/forward, cross-tab edits, manual URL edit). The page treats the URL as source of truth.

The locked row never exposes the artifact body. The user sees only the title (which the server already provides safely), agent attribution, version, status pill, and date.

## 6. Version handling behavior

The default view shows **latest versions only**. Toggle in the toolbar switches to **all versions**. Both modes preserve the rest of the filter selection.

Behavior verified against production data:

| Mode | Free tier rows | Starter tier rows |

The numeric version is captured in the row's title fallback for queued / generating / failed rows (`"Soul Map Synthesizer (failed)"`); for delivered rows, the agent's own `header.title` carries through.

## 8. Surprises and notes

### 8.1 Failed rows are not hidden

The free-tier list includes locked Visual DNA v1 and v2 rows, both `status=failed` from the step-5 prompt-tightening iterations. The archive shows these as "Locked" pills (since `locked` overrides `status` in the pill class lookup) and routes clicks to the paywall. Per spec §5.10, the server does not surface the body of locked artifacts in any case, so showing the failed row alongside the delivered v3 row is harmless: the user only sees "this artifact exists, was attempted, is locked." The actual failure detail (edge_timeout) lives in `artifact_runs.error`, which is not exposed by the archive.

### 8.2 Phase 02–05 filters are visible but disabled

Per spec 11.3, phases 02 through 05 render as disabled pills. They are not hidden — the user sees the system's full structure before subscribing. Clicking them does nothing (`pointer-events: none`).

### 8.3 The agent filter only shows produced slugs

If a user has zero Sensescape artifacts, the Sensescape pill does not appear in the agent filter. This keeps the filter compact for users mid-journey. The downside: the user does not see "this agent exists but I haven't run it yet" — that knowledge lives on the Foundation page (step 12), not the archive.

### 8.4 The locked-row glyph is `⌧` (U+2327)

A single Unicode lock glyph in mono, top-right. The qb-status-pill itself shows "Locked" text in the rose-deep variant. Together they make locked state legible from a glance at the row.

### 8.5 Hover lift respects reduced motion

Both `@media (prefers-reduced-motion: reduce)` and the manual `.qb-reduced-motion` class drop the row hover transform. The gallery toolbar carries a "Reduced motion" toggle for visual QA.

### 8.6 Filter bar collapses to a scrollable strip on mobile

At `<640px`, each filter group's pill row switches to `flex-wrap: nowrap` + `overflow-x: auto` with a 4 px scroll thumb. The user can swipe through phases / agents / statuses without the filter bar consuming the whole viewport. Desktop (`≥1024px`) puts all three filter groups + Reset on one row.

### 8.7 Title fallback honors the API contract

`/api/artifacts` already returns `title` computed from `content.header.title` with a status-aware fallback ("Artifact (generating)" etc.). The client-side `resolveTitle()` re-applies the fallback only when the server returned a generic "Artifact" — keeping the agent-named labels for cases where the server's fallback chain triggered. This double layer means the gallery (which builds rows from synthetic data) gets the same readable labels as production.
