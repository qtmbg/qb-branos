## 2. QBP fields the synthesizer reads

`visual-dna.html → saveToQBP()` was inspected. The Visual DNA exercise writes only these keys to `profiles.qbp`:

```
visualDnaCompletedAt
visualDnaKeepCount         (integer)
visualDnaDiscardRate       (integer, percentage)
visualDnaKeptImages        (array of image IDs, max 10)
visualDnaFastDiscards      (array of image IDs)
brandName
```

The image catalog's tag dictionary (weight, temperature, composition, subject, energy, era, finish, mood) is generated **randomly per session** by `generateMockImages()`. The tag mapping is in-memory only; it does not persist to QBP. This means a kept image ID like `img_27` has no stable meaning across the agent boundary — the synthesizer cannot resolve it to a color or texture.

The synthesizer therefore reads a wider field set than just `visualDna*`. Exported as `VISUAL_DNA_FIELDS`:

```
brandName,
visualDnaKeepCount, visualDnaDiscardRate,
visualDnaKeptImages, visualDnaFastDiscards,
colorTerritory, forbiddenColor, visualTerritoryNote,
typographyNote, antiVoice,
archetypePrimary, archetypeSecondary,
archetypeVisualImplications, archetypeVisualImplicationsFull
```

Visual DNA exercise outputs are kept as a quantitative signal (keep rate, fast-discard signature). The substantive palette/type inferences come from Sensescape color and typography fields and the archetype visual implications block. `footer.qbp_fields_referenced` is computed as `VISUAL_DNA_FIELDS ∩ present-in-QBP`.

## 6. Prompt and budget tuning

The initial Visual DNA prompt produced ~1500+ output tokens — significantly more than Soul Map (382) and Sensescape (484). At Sonnet 4.6's typical generation rate, that pushed total latency past the 22 s Edge-friendly cap.

### 6.1 Final prompt levers

| Lever | Before | After |
| --- | --- | --- |
| `MAX_TOKENS` | 4000 | 2400 |
| `CLAUDE_TIMEOUT_MS` | 22000 | 24000 |
| Per-section length | "two to four paragraphs" | "exactly two short paragraphs, 2–3 sentences each" |
| Palette rationales | "one or two sentences" | "one short sentence" |
| Type-pairing rationales | "one or two sentences" | "one short sentence" |
| Prompt verbosity | ~700 words | ~280 words |

Result: v3 ran in 21 s with 889 output tokens — within the new 24 s budget and well below the 2400-token cap.

## 8. Surprises and notes

### 8.1 Visual DNA exercise QBP gap

The Visual DNA exercise persists only quantitative signals (keep count, image IDs). The tag dictionary that powers the in-page report (`computeReportData` → `dominantKept`, `signatureTags`, etc.) is regenerated per session and never written to QBP. Without that signal in QBP, a Visual-DNA-only agent has no useful color or texture data to work with. The fix is either (a) modify `visual-dna.html` to persist the derived signature tags into QBP on save, or (b) accept the cross-pollination approach this agent now uses. Going with (b) for Chapter 1. Persisting `visualDnaSignatureTags` on the exercise side is the right structural fix; queued as known debt for whichever later step exposes the gap most clearly (likely step 18 end-to-end).

### 8.2 Output verbosity gap between agents

Visual DNA reliably produces 50–100 % more output tokens than Soul Map or Sensescape, even with the tighter prompt. Likely cause: the agent has two structured data blocks (palette with 4 swatches × {label, hex, rationale}, type_pairing with display + body × {family, weight, rationale}) on top of the prose, so there is more raw structure for the model to fill. Worth keeping in mind when sizing the War Table prompt in step 6 — positioning_map + priority_list + always_never is even more structure.

### 8.3 Lineage cleanup

The two failed rows (v1 and v2) live in `public.artifacts` with full timestamps and `parent_artifact_id` chains. They are not orphaned. A future "regenerate" UI built in step 7 (`/api/artifacts/[id]/regenerate`) will follow the same versioning pattern — failures and successes are versions of the same logical artifact, not duplicates.

### 8.4 Palette quality is plausible

The v3 palette for the test user (whose only meaningful QBP signal is the Rebel/Explorer/Hero archetype block) produced `#1A1A1A / #7A6A4F / #D4401A / #C8C2B8` — a defensible "outsider with terrain" reading of the archetype. Display Fraunces 700 + body IBM Plex Sans 400 is also defensible: editorial weight in display, technical neutrality in body. The agent leaned on archetype signals correctly when Sensescape data was empty.
