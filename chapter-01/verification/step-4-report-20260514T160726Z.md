## 2. QBP fields the synthesizer reads

Inspected `sensescape.html → saveToQBP()`. The exercise writes these keys to `profiles.qbp`:

| Field | Source prompt in sensescape.html |
| --- | --- |
| `colorTerritory` | `cstorydom` — what color territory the brand occupies |
| `forbiddenColor` | `cstorynever` — colors the brand refuses |
| `visualTerritoryNote` | derived string from sliders (photography vs illustration, contrast, time) |
| `typographyNote` | `tvoice` — typography as speaking voice |
| `antiVoice` | `vbvoicefail` — what the brand voice must never sound like |
| `brandObject` | `swobj` — the physical object the brand resembles |
| `brandMoment` | `swmoment` — a moment the brand resembles |
| `signatureGesture` | `rtsignaturerit` — the brand's signature ritual gesture |

These eleven fields are exported from the module as `SENSESCAPE_FIELDS`. `footer.qbp_fields_referenced` is computed as `SENSESCAPE_FIELDS` filtered to fields that were actually present in the user's QBP.

### 4.2 Foundation lock parallelism

```js
const AGENTS_TO_ENQUEUE = [
  'soul_map_synthesizer',
  'sensescape_synthesizer',
];

const dispatchResults = await Promise.all(
  AGENTS_TO_ENQUEUE.map(agentName =>
    runAgentDispatch({ req, token, userId: user.id, qbp: lockQbp, agentName })
  )
);
```

Each `runAgentDispatch` is a separate HTTP POST to `/api/agents/dispatch`, which runs on its own Edge worker with its own ~25 s budget. Parallel execution keeps total wall time close to the slowest single agent rather than the sum.

Response field renamed from `dispatch` (object) to `dispatch` (array). The only consumer is `dashboard.html`, which reads only `data.ok`, so no client-side break.

### 4.3 Budget headroom for steps 5–6

Two agents in parallel ≈ 7 s observed (Soul Map 7 s, Sensescape 5 s). Adding Visual DNA and War Table in steps 5 and 6 brings the parallel set to four. Each agent stays within its own Edge function budget. The lock-foundation outer call awaits all four; if the slowest runs near 20 s, the lock response could approach 25 s. Migrating to fire-and-forget via `event.waitUntil` is queued as known debt for whichever step exposes the timeout first.
