## 8. Surprises and notes

### 8.1 Test user QBP is archetype-only

The test user (`nizzar.ben+kvtest-srv-1037@gmail.com`) has 28 QBP keys — all in the archetype block — and zero Soul Map, Sensescape, Visual DNA, or War Table exercise outputs. So the page renders:

- Soul Axis: archetype card populated; essence / paradox / manifesto / anti-brand / commitments all show per-field empty lines
- Sensescape: full-section empty state ("complete the Sensescape exercise")
- Visual DNA (free): locked frost
- War Table (free): locked frost

This is exactly the realistic mid-journey shape Chapter 1 needs to support. The gallery state 2 ("Partial — archetype only, free tier") mirrors it.

### 8.2 No smell / taste fields in QBP

The Sensescape exercise (`sensescape.html`) does not write explicit smell or taste fields. The Sensescape Synthesizer derives those at artifact-generation time from adjacent signals. The QBP page therefore renders only the three sense groups it has user-provided data for (Sight, Sound, Touch). Documented inline in the renderer.

### 8.3 The QBP page does not duplicate artifact content

Each of the four sections renders what the user *provided* (or, for the archetype block, what the Compass diagnostically named). It does not surface the agent's synthesis output. For palette swatches, type pairing, positioning map, and ranked priorities, the page links the user to `/archive` to read the matching artifact through the editorial reading surface from step 9. This keeps the QBP/artifact separation clean: QBP = inputs, artifact = synthesis.

### 8.4 Foundation lock confirms after the fact

The test user's `foundation_locked_at` shows `2026-05-14T08:28:13.45+00:00` — populated during the earlier step-3 dispatch test. The QBP page surfaces "Locked" in the status badge accordingly. Pre-lock would show "Draft." Per spec edge case 10.2, exercises are immutable post-lock; the QBP page is read-only either way.

### 8.5 Export format honesty

`/api/qbp/export` returns `{ format: 'json', format_note: 'PDF export deferred to Chapter 1 polish pass; JSON ships full QBP content.' }`. The page surfaces the JSON-format label in the toast before download. No claim of PDF.

### 8.6 Locked sections show in the TOC

The TOC for free users lists all four sections and marks Visual DNA + War Table with a "Locked" pip. The user sees the document's full structure before they pay — the paywall isn't hiding the *existence* of paid content, just its body.

### 8.7 Print preview

The `@media print` block hides the toast, paywall modals, locked frosts, share controls, primary buttons, and status pills. Body sections, archetype card, and always/never lists set `page-break-inside: avoid`. Foundation locked badge becomes plain "Locked" mono text in print. Empty sub-blocks print their "Not yet captured" lines so the document is honest about gaps when printed.
